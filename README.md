# Paper-only support files

This folder contains the code and data for the Section 4 numerical results. Result CSV files use manuscript method names directly, and no unpublished benchmark is included.

- `results/strong_critic_regime_simulation_30seed_advantage_error_summary.csv` contains 480 controlled-critic runs.
- `long_horizon_regime_drl/results/sparse_trap_heterogeneity_sweep_30seed_mae_summary.csv` contains 750 DRL runs.
- The study runners regenerate their aggregate CSV files, paired tests, and result figures.
- The plot scripts regenerate Figures 2–7 in the two `figures` directories.
